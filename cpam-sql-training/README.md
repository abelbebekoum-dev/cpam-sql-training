# CPAM SQL Training — 100 jours de SQL et Power BI appliqués à l'assurance maladie

Projet d'entraînement quotidien sur une base **fictive** inspirée de l'activité d'une caisse primaire d'assurance maladie :
indemnités journalières, prestations en nature, arrêts de travail et contrôles de maîtrise des risques.

**Auteur :** Abel Bebe Koum — Gestionnaire Maîtrise des Risques, en transition vers l'analyse de données.

## Objectif
- 3 requêtes SQL par jour, sur des cas métier réalistes (détection d'anomalies, rapprochements, indicateurs).
- 1 rapport Power BI chaque vendredi.
- Une base qui grossit par étapes : v1 (≈15 pages) → +20 → +30 → +50 → 100 pages.

## Structure
| Dossier | Contenu |
|---|---|
| `data/v1/` | Base SQLite, script SQL, CSV |
| `docs/` | Dictionnaire de données et règles de gestion (PDF) |
| `missions/` | Énoncés hebdomadaires |
| `solutions/` | Mes requêtes, une par fichier |
| `powerbi/` | Rapports hebdomadaires (.pbix + captures) |
| `suivi/` | Journal de progression |

## Compétences démontrées
SQL (jointures, agrégats, CTE, fonctions de fenêtrage, contrôles de cohérence) · Power BI (modélisation, DAX) · Git / GitHub

> Toutes les données sont générées et fictives. Aucune donnée réelle d'assuré n'est utilisée.
